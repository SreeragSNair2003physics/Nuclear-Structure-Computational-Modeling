# 🔬 Nuclear Dynamics & Quantum Eigenvalue Solvers
This repository is where I break down nuclear physics models into Python code and visualizations. It started out as my MSc thesis project, but I’m still actively writing and adding to it because I like seeing how these massive equations look when you plot them out.

## 🚀 What’s Working Right Now
*   **SEMF & Liquid Drop Model:** Solid Python code using `matplotlib` that calculates nuclear binding energies. It generates clean plots for the binding energy curve and tracks down the Beta stability line and drip lines.
*   **Quantum Shell Model:** Basic numerical script using the Harmonic Oscillator potential to isolate magic numbers and visualize basic quantum energy states.

## 🛠️ Current Work in Progress (ASAP Additions)
*   **The Nilsson Model:** I started writing a matrix solver to account for spin-orbit coupling and structural deformations. It's not fully finished or functional yet, but I'm actively teaching myself the required linear algebra transformations to get the eigenvalue diagonalisation working.
